
# AI Resume & Job Matcher

An AI-powered resume analysis application built using Python and Streamlit.

## Features

- Upload resumes in PDF, DOCX and TXT formats
- Extract resume text
- TF-IDF and Cosine Similarity using pure Python
- Resume and job description matching
- Skill detection
- Matched and missing skill identification
- Resume improvement suggestions
- Learning recommendations
- Interactive dashboard
- Downloadable PDF analysis report

## Tech Stack

- Python
- Streamlit
- PyPDF
- Python-docx
- ReportLab
- TF-IDF
- Cosine Similarity

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project:

```bash
cd AI-Resume-Job-Matcher
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
